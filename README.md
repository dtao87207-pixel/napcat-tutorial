# 用 AstrBot + NapCat 在 QQ 上养一只「大肥鱼」

一份**全流程实操教程**：从零把 AstrBot 跑起来，用 NapCat 挂一个小号，接通对话模型与
视觉模型，写一个人格，配好陪伴插件和表情包，最后让它在群里不 @ 也能自然接话。

不是概念介绍，是每一步都带命令、带报错、带踩坑记录的操作手册——审过一遍，能照着跑通。

## 内容

| 章节 | 讲什么 |
|---|---|
| 0 | 三条路线怎么选，A 方案为什么废了 |
| 1–2 | 整体架构与准备工作 |
| 3 | 装 AstrBot（源码 + venv + 首次启动与面板密码） |
| 4 | NapCat 挂小号（免装 QQ，OneKey 安装器） |
| 5 | 把两者接起来：反向 WebSocket 配置与连通性排查 |
| 6 | 接模型：DeepSeek 负责说话和工具调用，GLM-4V 负责看图 |
| 7 | 人格提示词：一个人格该写什么、怎么设为默认 |
| 8 | 陪伴插件：主动强度四档、配置结构里的坑 |
| 9 | 表情包（最折腾的一步）：加速器、并行下载、资源包来源 |
| 10 | 群聊怎么才能不 @ 也接话：四处白名单、唤醒策略 |

## 发布前改了什么

这份教程原本是给自己留的操作记录，公开前把两类东西换成了占位符：

- 面板/部署口令 → `ChangeMe-Please`
- 服务器地址 → `your-server.example.com`

照着做的时候，把这两处换成你自己的即可。**不要把真实口令提交进仓库。**
